# 크라임씬플레이 예약 알림

크라임씬플레이 서면점의 새 예약과 예약 취소를 확인하는 사장님용 안드로이드 앱입니다.

## 처음 사용할 때

1. APK를 설치합니다.
2. 앱을 열고 관리자 페이지에서 사용하는 암호를 입력합니다.
3. 알림을 허용합니다.

연결은 처음 한 번만 하면 됩니다. 이후 새 예약이 들어오면 휴대폰 알림으로 표시되고, 앱 안에도 내역이 남습니다.

## 알림이 늦을 때

휴대폰의 배터리 절전 기능이 앱을 강제로 멈추면 알림이 늦을 수 있습니다. 휴대폰 설정에서 이 앱의 배터리 사용을 제한하지 않도록 설정해 주세요.

## 보안

관리자 암호는 앱에 저장하지 않습니다. 연결이 끝나면 해당 휴대폰 전용 연결 정보만 발급하며, 연결 정보와 예약자 연락처는 휴대폰 보안 저장소로 암호화합니다. 앱 백업도 허용하지 않습니다.
