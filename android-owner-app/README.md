# 크라임씬플레이 예약 알림 앱

서면1호점 사장님 휴대폰에 새 예약과 취소 요청을 알려주는 안드로이드 앱입니다.

## 사용 방법

1. APK를 설치합니다.
2. 처음 실행할 때 관리자 페이지에서 사용하는 암호키를 입력합니다.
3. 알림 허용을 누릅니다.
4. 이후 새 예약이 들어오면 휴대폰 알림으로 표시되고 앱 안에 계속 보관됩니다.

앱을 완전히 닫아도 예약을 놓치지 않도록 낮은 중요도의 `예약 알림 수신 중` 알림이 유지됩니다. 휴대폰 제조사의 배터리 절전 기능이 앱을 강제로 종료하면 알림이 늦어질 수 있으므로 이 앱은 배터리 사용 제한에서 제외하는 것을 권장합니다.

## 보안

- APK 안에는 관리자 암호키나 예약 데이터 접근 토큰이 들어 있지 않습니다.
- 처음 연결할 때 관리자 암호키를 서버에서 확인한 뒤 휴대폰 전용 토큰을 발급합니다.
- 토큰과 예약자 전화번호는 Android Keystore로 암호화해 휴대폰 안에 저장합니다.
- 앱 백업은 비활성화되어 있습니다.
